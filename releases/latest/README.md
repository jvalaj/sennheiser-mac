# Latest build

Pre-built **Accentum** menu bar app for macOS 26+.

## Download

1. Download [`Accentum.app.zip`](./Accentum.app.zip)
2. Double-click to unzip
3. Drag **Accentum.app** to **Applications**
4. Open it — allow **Bluetooth** when macOS asks
5. Pair your headphones in **System Settings → Bluetooth** first

## Notes

- This is an ad-hoc signed dev build. If macOS blocks it, right-click → **Open** once.
- **USB-C wired:** the app detects cable audio and won’t force Bluetooth. Tap **Bluetooth** in the menu when you want noise-control from the Mac.
- If connection fails, close **Sennheiser Smart Control** on your phone.

Built from `main` on push — for source builds, see the [repo README](../../README.md).
